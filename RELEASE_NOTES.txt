NightView 1.6.12
- 이미지 보기 중 Delete 키로 현재 이미지 빠른 삭제 추가
- Delete는 확인창 없이 Windows 휴지통으로 이동하며 영구 삭제하지 않음
- 삭제 성공 후 다음 이미지가 있으면 즉시 다음 이미지로 이동
- 마지막 이미지를 삭제한 경우 바로 이전 이미지로 이동
- 폴더의 마지막 한 장까지 삭제하면 NightView 빈 상태로 전환
- GDI+ 파일 잠금을 먼저 해제한 뒤 휴지통 이동해 삭제 실패 가능성 최소화
- 삭제 실패 시 원본 이미지를 다시 로드하고 오류만 표시
- 이미지 로딩 중 Delete 입력은 파일 경합 방지를 위해 무시
- 기존 ESC 종료, 좌우 이동, 전체화면, 탐색기 실제 순서 정렬, AI 4K, 업데이트/롤백 기능 유지
