NightView 1.6.3
- 프로그램 실행 시 일반 창이나 단순 최대화가 아니라 F11과 같은 테두리 없는 전체화면으로 바로 시작
- 전체화면은 현재 모니터 영역을 정확히 채우며 기존 F11 전환 기능 유지
- ESC 키를 누르면 전체화면 해제 대신 NightView 자체를 즉시 종료
- 수동으로 업데이트 확인을 눌렀을 때 새 버전이 있으면 중복 확인창 없이 바로 다운로드 -> 교체 -> 자동 재실행
- 프로그램 시작 시 자동으로 새 버전을 발견한 경우에는 설치 여부 확인창 유지
- 고정 설치 경로의 기존 NightView.exe 교체 방식 유지
- 설정과 사용자 데이터 보존 및 업데이트 실패 시 백업/롤백 유지
