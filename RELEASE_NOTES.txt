NightView 1.6.10
- 1.6.9의 탐색기와 동일하게 정렬이 실제 탐색기 순서를 복제하지 못하던 문제 수정
- 같은 폴더를 열고 있는 Windows 탐색기 창의 실제 Folder.Items 표시 순서를 읽어 이미지 파일만 그대로 필터링해 사용
- 탐색기의 이름/수정 날짜/날짜/생성 날짜/크기 등 현재 정렬 기준과 오름차순/내림차순 결과를 그대로 반영
- 탐색기에서 폴더가 먼저 표시되거나 비이미지 파일이 섞여 있어도 NightView 지원 이미지들의 상대 순서는 탐색기와 동일하게 유지
- 같은 폴더의 탐색기 창이 열려 있지 않으면 잘못된 유사 정렬을 적용하지 않고 안내 표시
- 정렬 변경 후 현재 보고 있던 이미지는 그대로 유지
- 기존 탐색기식 파일명 비교 StrCmpLogicalW는 폴백/기존 테스트용으로 유지
- 기존 전체화면 툴바, 이미지 형식/WEBP 판별, 파일 연결, AI 4K 저장/비교, 업데이트/롤백 기능 유지
