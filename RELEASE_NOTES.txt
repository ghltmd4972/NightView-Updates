NightView 1.6.11
- 탐색기/Bandizip 등에서 이미지 파일을 지정해 실행할 때 1280x800 빈 NightView 창이 먼저 노출되던 문제 수정
- 이미지 파일 시작은 숨김 창으로 생성하고 첫 이미지 디코딩 완료 전까지 화면에 표시하지 않음
- 첫 이미지가 준비되면 숨김 상태에서 전체화면 크기와 맞춤 배치를 먼저 완료한 뒤 한 번에 표시
- 이미지 실행 시 창모드 -> 전체화면으로 전환되는 중간 화면 제거
- NightView.exe를 이미지 없이 단독 실행하는 경우 기존 빈 시작 화면 동작은 유지
- 이미지 로드 실패 시에는 오류 확인이 가능하도록 NightView 창을 표시한 뒤 오류 메시지 출력
- 기존 전체화면 툴바, 탐색기 실제 순서 정렬, WEBP/파일 형식, 파일 연결, AI 4K 저장/비교, 업데이트/롤백 기능 유지
