NightView 1.6.8
- 확장자와 실제 이미지 형식이 달라도 WEBP 파일 헤더를 직접 판별해 정상 열기
- .png 또는 .jpg 이름으로 저장된 실제 WEBP 파일도 자동 감지 후 정상 표시
- 기존 NightView.Image 공용 파일 형식 표시명을 NightView 브랜드명이 아닌 이미지 형식으로 변경
- 기존 NightView.Image 파일 아이콘을 NightView.exe 아이콘 대신 Windows 이미지 아이콘으로 교체
- 앞으로 PNG/JPEG/GIF/BMP/TIFF/ICO/WEBP별 개별 ProgID를 등록해 파일 속성에서 실제 형식명이 표시되도록 개선
- PNG는 Windows 기본 PNG 이미지 아이콘, JPEG는 Windows 기본 JPEG 이미지 아이콘, 나머지는 Windows 이미지 아이콘 사용
- 1.6.7 사용자는 1.6.8 최초 실행 시 associations-v3 마이그레이션으로 자동 복구
- Windows의 기존 확장자 기본 ProgID와 썸네일 처리기는 계속 보존
- 기존 전체화면 툴바, 창 제어, AI 4K 저장 선택/원본 비교, 업데이트/롤백 기능 유지
